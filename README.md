# 📧 Email Popup Project

## 📌 About the Project
This project is an Email Signup Popup created using HTML, CSS, and JavaScript.

The popup appears automatically after 3 seconds and allows users to enter their email address to sign up.

## 🚀 Features
- Popup appears after 3 seconds.
- Email input with validation.
- Close button to dismiss the popup.
- Click outside the popup to close it.
- Responsive design for mobile and desktop.
- Success message after form submission.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
